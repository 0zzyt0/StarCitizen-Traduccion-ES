# Referencia en inglés (opcional)

Si subes aquí el `global.ini` original en inglés de cada canal (`referencia/LIVE/global.ini`,
`referencia/PTU/global.ini`…), la validación comprobará además que la traducción no ha perdido
claves ni marcadores protegidos (`~mission(...)`, `<EM4>`, `%ls`, `{...}`, `\n`).
Estos archivos no se distribuyen a los jugadores.
